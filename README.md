# PeerEd (working name)

Wartime regional learning network: university students <-> school pupils matched by region,
short "enrichment units", and a teacher <-> student gateway for everything AI-related.

Owner idea, 2026-09-07. Research-first: no product code until PURPOSE.md is grounded in research
(see the Perplexity request in the research queue). Rules: no cloud dependency for the MVP,
no personal data of minors, deterministic tests only.
